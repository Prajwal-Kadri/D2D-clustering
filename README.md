# Distance-Based D2D Clustering

An ns-3 simulation of device-to-device (D2D) clustering for a 5G-style cellular setting. The implementation groups user equipment according to distance from the eNodeB and evaluates the resulting communication setup.

## Repository contents

- `IT_200_Project.c` — simulation implementation
- `README.md` — project documentation

## Running

This project is designed to be built inside a compatible ns-3 environment. Copy `IT_200_Project.c` into the appropriate ns-3 scratch or examples directory, build it with the version of ns-3 used for the project, and run the resulting simulation.

## Notes

The code was developed from ns-3 sample code and adapted for the project’s distance-based clustering policy. It is best treated as an academic simulation artifact rather than a ready-to-deploy networking system.
